# AMOY Consultancy — Official Web Portal & Community Hub

> University-anchored student consulting group bridging academic rigor with practical SME digitalization and operational efficiency in Mersin, Türkiye.

---

## 📁 Repository Structure

├── index.html              # Main website file (Tailwind CSS, FontAwesome, fully responsive)
├── COMMUNITY_DOSSIER.md    # Operating model, roles, mentor network, and strategy
├── README.md               # Deployment and customization guide
└── assets/                 # Brand assets directory
    ├── logo.png            # Recommended size: 512x512 PNG (transparent background)
    └── favicon.ico         # Website favicon

---

## 🚀 How to Deploy on GitHub Pages

1. **Upload Files:** Ensure `index.html` is in the repository root.
2. **Add Assets:** Place your `logo.png` and `favicon.ico` in the `assets/` folder.
3. **Enable Pages:** In your repository, navigate to **Settings** > **Pages**.
